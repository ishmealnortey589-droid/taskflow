# Taskflow – Kanban Board

A browser-based Kanban task board built for the SkillMe Full Stack Engineer Virtual Internship.

## Features
- Three columns: To Do, In Progress and Done, each with a task count
- Reusable `.task-card` styles with colour-coded priority labels (Low, Medium, High)
- Add, move and delete tasks with JavaScript
- Responsive: columns stack vertically below 700px

## Tech
HTML, CSS (Grid + CSS variables), vanilla JavaScript

## Run locally
Open `index.html` in your browser.
